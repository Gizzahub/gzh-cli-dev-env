# 전환 전 상태 조회 계약

AWS, GCP, Azure, Docker, Kubernetes의 `GetCurrentState`는 조회 명령의 실패와 취소를 오류로 반환한다. 일부 조회가 성공했더라도 다음 조회가 실패하면 부분 상태를 반환하지 않는다. 정상 종료한 명령의 빈 출력은 빈 값으로 유지하며 임의의 기본 상태를 만들지 않는다.

AWS 프로필은 `AWS_PROFILE`, 라이브러리가 관리하는 활성 프로필 파일, 빈 값 순서로 결정한다. 환경 변수로 결정되지 않은 경우 파일 읽기 실패는 상태 조회 오류다. 기존 상태 표시용 조회의 최선 노력 동작은 유지한다.

환경 전환 관리자는 상태 조회가 실패한 서비스를 저널에 기록하거나 전환하지 않는다. 첫 서비스의 조회 실패를 검증하는 테스트는 실제 변경 모드에서도 저널 생성과 전환·롤백 호출이 없는지 확인한다. 서비스별 테스트는 테스트 실행 파일과 호출별 실행 주입을 사용하며 실제 공급자 CLI나 사용자 설정을 변경하지 않는다.

이 계약은 공급자별 비정상 종료가 정상적인 미설정을 뜻한다고 가정하지 않는다. 빈 상태의 완전한 복원, 여러 서비스 전환 전체의 원자성, 메인 CLI의 라이브러리 연결은 별도 범위다. 이 소스 수정은 기존 출시 후보 태그나 게시 승인을 변경하지 않는다.
